# Bachelorarbeit – Automatisierte Microsegmentierung

Dieses Repository enthält Materialien und Arbeitsstände zur Bachelorarbeit **„Automatisierte Microsegmentierungsstrategie basierend auf Digital Twin Netzwerk-Mapping“**.
Ziel der Arbeit ist die Entwicklung eines prototypischen Systems zur **automatischen Generierung von Microsegmentierungsregeln auf Basis eines graphbasierten Netzwerkmodells**.

Die Arbeit untersucht, wie Netzwerke als Graph modelliert werden können, um Kommunikationsbeziehungen zu analysieren und daraus minimale, sicherheitsoptimierte Regelwerke abzuleiten.

## Repository-Struktur

```
.
├── README.md

├── papers
│   └── pdf

```

### `docs/`

Interne Dokumentation zum Projekt, z.B.:

- Architekturüberlegungen
- Designentscheidungen
- Notizen zu Implementierung und Experimenten
- Meeting-Notizen

### `papers/`

Sammlung relevanter wissenschaftlicher Arbeiten und Literatur.

```
papers/
└── pdf/
```

Die PDF-Dateien dienen als Grundlage für die Literaturrecherche und den Related-Work-Teil der Thesis.

### `thesis/`

LaTeX-Quellen der schriftlichen Bachelorarbeit.

Hier befinden sich:

- Hauptdokument der Arbeit
- Kapitelstruktur
- Abbildungen und Tabellen

## Geplante Inhalte des Projekts

Im Verlauf der Arbeit werden zusätzlich folgende Komponenten entwickelt:

- **Prototypische Implementierung** eines Systems zur automatisierten Microsegmentierung
- **Graphbasierte Modellierung von Netzwerken**
- **Algorithmus zur Generierung minimaler Kommunikationsregeln**
- **Evaluation in einer Testumgebung** (z.B. Containerlab)
